## Direction contract

THESIS: 一台安静的家用小设备：机身上开一扇海报窗口说此刻最该做的一件事，下面是圆键、胶囊键和一块读数屏。拒绝「地图头图 + 卡片 + 一种蓝」，也拒绝暗底极客屏。

OWN-WORLD: 浅暖灰机身、近白面板、圆形日期键、胶囊同行者键；全机只有一颗橙色主键，太阳也是这颗橙；绿色只表示没问题。窗口里是平涂层叠山景（青灰天、橄榄绿山），一句话标题用方块字压在近山上。读数用细体大数字，「谁定的」用通道色点，问题只给短标签。

STORY: 一眼看到：现在该做什么（窗口标题）、今天第几天、谁的上限多少、曲线离上限多远、下一站与「到了」键。

FIRST VIEWPORT: 顶部海报窗口（山景 + 一句话 + 地名 / 天数 / 时刻）；一排五个圆形日期键；同行者胶囊键；读数屏（累计游玩曲线与每人触发线）；四格读数；下一站卡片与橙色「到了」键。

FORM: 博朗面板（第三手我的首选）× 公园海报（第三手竞争方向）的顶部窗口，用户指定融合，seed 38f61ea7。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Interaction brief（2026-09-28 用户确认）

- 主要用法：AI 排好行程，用户微调；单手、手机。改一处 ≤ 3 次点击，改完立刻看到限制怎么变。
- 浏览为主，编辑进底部面板：列表只显示摘要，点一项从底部拉起面板，往下拖可关、拖到一半能反悔；一次只编辑一件事。
- 大控件代替输入框和下拉：步进器（年龄、时长）、分段键（行动能力、优先级）、磁贴（类别）、天数条（按住划选连续的天）；只有名字用输入框。
- 常用的在第一层，少用的收进「更多」。
- 改动即时显示影响：面板底部写出「这样改之后」（上限变化 / 解决了 / 新问题 / 数字变了）。
- 撤销代替确认：删除、打卡、跳过直接生效，底部 5 秒撤销；只有「恢复示例旅程」确认。
- 按下即反馈，目标 ≥ 44px；面板与拖动用不回弹的弹簧；减少动态效果时改为淡入淡出。
- 各页：同行＝摘要卡 + 两步加人；行程＝点开一天，左滑跳过 / 删除，把手拖动排序，点站点开面板，「加一站」先选类别；今天＝站点与问题标签都可点开面板；红黑榜＝红 / 黑两个大键起手。
- 海报窗口只在「今天」；按时段（清晨 / 白天 / 傍晚 / 夜里）换色，夜里换成月亮；不做定时刷新，回到页面时重算。
